# PRETEND CO.

Lost games from a studio that never existed.

Open any `index.html` in a browser (or serve the folder with `python -m http.server`) — no build step.

**Generation 1 — handheld (160×144, 4 shades)**
- `index.html` — CARL: Above & Below Nevada
- `linda/` — CEO LINDA
- `ghost/` — SPOOKY GHOST: Live From Beyond
- `tp/` — TP: Throwing In The Towel

**Generation 2 — SUPER-16 (320×224, 512 colors, FM sound)**
- `pk/` — PEE KID³: Third Time's the Charm

Controls (Gen 2): arrows move, Z = A, X/Space = B, C = C, Enter = Start. F = fullscreen.

See `HANDOFF.md` for how everything is built and tested.
